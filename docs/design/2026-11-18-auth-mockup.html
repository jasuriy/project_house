Login, signup and account screens

Drawn in the approved system: palette 2, Inter, the same header, radii and type scale as the five main screens. Desktop first (1280), phone last (390). Google and GitHub buttons appear only when those logins are switched on. Uzbek interface text is a first draft.

1. Kirish (log in)

One centred card. The quick path first (Google, GitHub), then email and password. "Parolni unutdingizmi?" sits on the password label. The sign-up link is at the bottom, because phones reach sign up only from here.

2. Kirish: error states

Left: wrong email or password (one message above the button, the same for both cases). Right: arriving from Google when an account with that email exists (the yellow banner from the design guide, with what to do next).

3. Roʻyxatdan oʻtish (sign up)

Account type first (two large choices), then email, password, username (shows the profile address it creates) and name. Errors appear under their field; here the username is already taken.

4. Phone

The same cards full width with 16 px page padding; every input and button is 44 px tall.

5. Parolni tiklash (forgot password)

Desktop: the form. Phone: after sending. The message is the same whether or not the email has an account, so nobody can learn which emails are registered.

6. Yangi parol (reset password)

Opened from the emailed link (the link is removed from the address bar). Desktop: the form. Phone: success (all devices are logged out, so the next step is logging in) and an expired link (the next step is a new link).

7. Emailni tasdiqlash (verify email)

The link works only while logged in to that account (security rule). Desktop: confirmed. Phone: expired or opened in another account; and the login page when the visitor is not logged in, with a blue note saying why.

8. Xush kelibsiz (onboarding)

After the first sign-up (email or Google/GitHub). Desktop: email sign-up (asks to confirm the email). Phone: a Google/GitHub sign-up (email already confirmed by the provider, no note).

9. Sozlamalar (settings)

Email with its status and the connected Google/GitHub accounts. Desktop: confirmed email, Google connected, GitHub can be connected. Phone left: email not confirmed (connecting is blocked by the security rule, so the page says how to confirm, including the password-reset route). Phone right: coming back from GitHub when that GitHub account belongs to someone else.

10. Profilni tahrirlash (edit profile)

Opened from "Profilni tahrirlash" on your profile and from Sozlamalar. The photo row at the top saves on its own (part of the add-project work, 2026-11-18). Fields depend on the account type. Desktop: a developer, everything filled in. Phone left: the GitHub link is not a github.com address, so the error sits under that field after saving. Phone right: a company account (role, company name, About the company, website). After a successful save a green "Saqlandi" banner appears at the top.
